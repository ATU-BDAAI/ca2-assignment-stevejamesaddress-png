## **Running the Notebook**

##### Test Input

The processing reads all test files in the directory. There are 6 supplied files although the yolo were really to test it as childrens images failed! You can add your own image as long as for jpg, jpeg, png. If its a real file you want to compare then add a ground truth to test_data in the truth testing cell.

##### OCR Tesserat

You will need to update the CONST_TESSERAT_PATH to the local installation. Lab depends on being on windows.

#### Execute

Make sure to run all cells as the logically follow each other. An error message informing that is in place.

##### Disable Trace

disable trace set CONST_TRACE = False
